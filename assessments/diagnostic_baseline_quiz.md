# Pre-Course Assessment Quiz: AI & ML in Bioinformatics

This short quiz is designed to help assess your current comfort level with the tools, languages, and concepts we will use in this course. **This is not graded!** It simply helps the instructor understand the class's baseline so we can tailor the pacing of the sessions.

---

### Category 1: IDEs & Cloud Notebooks
1. **Basic:** What is the main difference between a standard Python script (`.py`) and a Jupyter Notebook (`.ipynb`)? Why might we prefer Jupyter for data exploration?
2. **Advanced:** If you are using Google Colab and training a model is taking too long, how do you change your runtime hardware to utilize a free GPU?

### Category 2: Operating System
1. **Basic:** What is the difference between an *absolute* file path (e.g., `/home/user/data/genes.csv`) and a *relative* file path (e.g., `../data/genes.csv`)? 
2. **Advanced:** In your preferred operating system (Windows, macOS, or Linux), how do you check how much memory (RAM) is actively being used by a specific application?

### Category 3: Command Line (Terminal)
1. **Basic:** What two terminal commands would you use to navigate into a folder named `bio_data` and then list all of the files inside it?
2. **Advanced:** You want to execute a python script named `train_model.py` from the terminal, but you want to save all of the printed output to a text file named `logs.txt` instead of seeing it on the screen. How would you write that command?

### Category 4: Languages & Dev Tools (Python, Git, Conda)
1. **Python (Basic):** Given the list `data = [1, 2, 3, 4, 5]`, write a simple Python code to create a new list where every number is squared.
2. **Git (Intermediate):** You have just edited a script and saved it. What are the three standard `git` commands you need to type to stage your changes, save a snapshot with a message, and send it to your GitHub repository?
3. **Conda (Basic):** Why is it considered a "best practice" to create a fresh Conda environment for a new ML project, rather than `pip install`-ing everything into your base environment?

### Category 5: Domain Knowledge (Stats, Math, Biology)
1. **Biology (Basic):** According to the central dogma of molecular biology, DNA is converted into RNA, which is then translated into Proteins. What is the specific biological term for the process of converting DNA to RNA?
2. **Statistics (Basic):** If you calculate the standard deviation of a dataset (like a list of gene expression levels) and the result is exactly `0`, what does that tell you about the numbers in your dataset?
3. **Math (Basic):** In Machine Learning, we constantly manipulate matrices. If you multiply a matrix with the shape `(3, 4)` by a matrix with the shape `(4, 2)`, what will be the dimensions of the resulting matrix?
