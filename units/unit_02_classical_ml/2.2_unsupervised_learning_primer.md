# 🔍 Unsupervised Learning: Dimensionality Reduction & Clustering

In supervised learning (such as classification and regression) — every training sample comes with a known target label $y$ (such as *Malignant vs. Benign* or a numerical drug dosage).

In **Unsupervised Learning**, we have **no target labels**. We are given only the input features $X$:

```
                               UNSUPERVISED LEARNING
                            (Features Only — No Labels)
                                        │
             ┌──────────────────────────┴──────────────────────────┐
             ▼                                                     ▼
   1. DIMENSIONALITY REDUCTION                               2. CLUSTERING
(Compressing Features into Fewer Axes)            (Grouping Similar Samples Together)
  • Principal Component Analysis (PCA)              • K-Means Clustering (Partitioning)
  • t-SNE (Neighborhood Embedding)                  • Hierarchical Clustering (Dendrograms)
```

Unsupervised learning addresses two fundamental computational challenges in modern biology:
1. **The Curse of Dimensionality:** In high-throughput genomics, we often measure 20,000 genes for only 100 patients ($p \gg n$). We cannot visualize 20,000 dimensions at once, and many genes carry redundant or noisy signals. **Dimensionality reduction** compresses this space into a few informative dimensions.
2. **Discovering Hidden Biological Subtypes:** When profiling unannotated tumor biopsies or cell populations, pathologists often do not know how many distinct disease subtypes exist. **Clustering** discovers these natural groupings purely from feature similarities.

---

## 1. Dimensionality Reduction

### What Is It?
**Dimensionality reduction** is the process of obtaining a compact representation of high-dimensional data by reducing the number of input features while retaining as much meaningful information as possible.

### Why Do We Need It?
1. **Reduces Noise and Redundancy:** Many genes in a biological pathway are co-regulated; their expression levels rise and fall together. Keeping 50 identical signals wastes computational power and introduces collinearity.
2. **Enables Visual Exploration:** Human eyes can only see in 2D or 3D. Dimensionality reduction allows us to plot a complex 20,000-gene dataset on a standard scatter plot.
3. **Improves Downstream Machine Learning:** Fitting supervised models (like logistic regression) or clustering algorithms on thousands of raw features often leads to overfitting. Feeding a compact set of reduced components improves speed, stability, and predictive performance.

---

### Method 1: Principal Component Analysis (PCA) — Linear Reduction

**Principal Component Analysis (PCA)** is a linear technique that creates new axes called Principal Components (PCs) to represent the data. PC1 captures the largest amount of variation in the data, PC2 captures the next largest amount, and so on. Each new component is perpendicular to the previous one.


#### When to Use PCA
* As a fast, reliable preprocessing step to reduce dimensions before training supervised models (like SVM or Random Forest) or running clustering algorithms.
* When exploring data via 2D/3D visualization

#### Biological Use-case Example: Bulk RNA-seq Tumor Profiling
Imagine we have RNA-seq data from 120 (60 tumor, 60 normal) patient samples, with 20,000 genes measured in each sample.
* Looking at all 20,000 genes individually would be difficult.
* PCA reduces these 20,000 gene measurements into a few summary dimensions, such as PC1 and PC2.
* When we plot PC1 against PC2, we may see tumor samples and healthy samples forming separate groups.

---

### Method 2: t-Distributed Stochastic Neighbor Embedding (t-SNE) — Non-linear Reduction

**t-SNE** is a non-linear technique designed specifically to map high-dimensional data into 2D or 3D while preserving **local neighborhood relationships**. It ensures that points that are close together in high dimensions remain close together in the low-dimensional map.

#### When to Use t-SNE
* **Exclusively for 2D or 3D visual exploration** of complex single-cell datasets, mass cytometry (CyTOF), or deep learning embeddings.
* When you want to see if discrete biological subpopulations or cell clusters exist.
* **When NOT to use t-SNE:**
  * **Never use t-SNE coordinates as features for downstream machine learning models.** Distances between distant clusters and cluster sizes in t-SNE are arbitrary.
  * **Cannot project new test samples:** Unlike PCA, t-SNE does not learn a reusable projection matrix. If a new patient arrives, you cannot project them onto an existing t-SNE plot without re-running the entire algorithm from scratch.

#### Biological Use-case Example: Single-Cell RNA-seq (scRNA-seq) Immune Cell Atlas
Imagine we have 15,000 individual white blood cells and want to identify different cell types.
* PCA: Because PCA is linear, different cell types may appear as overlapping or continuous groups in the 2D plot.
* t-SNE: t-SNE can capture more complex, nonlinear relationships and often produces clearly separated clusters or “islands” representing different cell populations.

## 2. Clustering

### What Is It?
**Clustering** is the process of grouping similar samples together into subsets (called *clusters*) based entirely on their feature profiles, without using any predefined class labels.

### Why Do We Need It?
Clustering helps us discover natural groupings, hidden sub-types, or functional patterns in biological data when no diagnosis or class label is provided in advance. Once clusters are formed, researchers can inspect the clinical outcomes or biomarker expressions of each cluster to discover previously unrecognized biology.

### How It Works: Similarity Definitions
Different clustering algorithms use different strategies and definitions of similarity:
* **Distance to Center (Partition-based):** Samples are assigned to the nearest central hub ($K$-Means).
* **Step-by-Step Merging (Connectivity-based):** Individual samples are linked together based on pairwise similarity to build a nested hierarchy (Hierarchical Clustering).

---

### Method 1: $K$-Means Clustering (Partition-Based)

**$K$-Means** partitions a dataset into a predefined number of non-overlapping clusters ($K$). 
1. The algorithm randomly places $K$ initial cluster centers (called **centroids**).
2. Each sample is assigned to its closest centroid using Euclidean distance.
3. Each centroid recalculates its position by taking the average (mean) of all samples assigned to it.
4. Steps 2 and 3 repeat iteratively until the centroids stop moving.

```
                           THE K-MEANS ITERATION CYCLE
     ┌──────────────────────────────────────────────────────────────────┐
     ▼                                                                  │
1. Initialize K Centroids ──► 2. Assign Samples to ──► 3. Recalculate Centroids
   (Random placement)            Nearest Centroid         (Mean of assigned points)
```


#### When to Use $K$-Means
* When you want clear, separate groups.
* When the clusters are roughly round and similar in size.
* When you have a large dataset, because K-Means is fast and scales well.


---

### Method 2: Hierarchical Clustering (Connectivity-Based)

**Hierarchical Clustering** builds a nested tree of clusters. The most common form in bioinformatics is **Agglomerative (bottom-up)** clustering:
1. Every individual sample begins in its own single-element cluster.
2. The algorithm finds the two most similar samples in the dataset and merges them into a pair.
3. It continually merges the closest pairs or existing groups step-by-step.
4. The process continues until all samples are merged into a single unified root, recorded as a tree called a **Dendrogram**.

```
                   AGGLOMERATIVE DENDROGRAM (BOTTOM-UP)
                   
                           ┌───────────────┐  Root (All samples in 1 cluster)
                           │               │
                       ┌───┴───┐           │
                       │       │           │  [Cutting the tree horizontally
                     ┌─┴─┐   ┌─┴─┐       ┌─┴─┐ reveals distinct clusters!]
                     │   │   │   │       │   │
                     A   B   C   D       E   F  Individual Samples
```


#### When to Use Hierarchical Clustering
* When you do not know the number of clusters in advance.
* When you want to create a dendrogram or heatmap, especially for small to medium datasets.
* Useful for finding groups of genes or samples with similar patterns and visualizing their relationships.

## 3. Practical Bioinformatic Best Practices

### The Golden Rule: Always Standardize Continuous Features First

Both PCA and $K$-Means are affected by differences in feature scale.

In biological data, different features operate on vastly different numerical scales:
* A highly expressed housekeeping gene (like *GAPDH* or *ACTB*) might have raw expression counts between **10,000 and 50,000**.
* A crucial master regulator transcription factor (like *TP53* or *SOX2*) might have counts between **2 and 15**.

If we feed raw, unscaled numbers into PCA or $K$-Means:
* High-count genes can dominate the analysis simply because their numbers are larger.
* Low-count genes may have important biological variation but contribute much less.

**Rule:** Always apply **`StandardScaler`** ($Z$-score scaling: mean $= 0$, standard deviation $= 1$) before running PCA or distance-based clustering. This guarantees every gene contributes equally based on its relative variation, rather than its arbitrary baseline volume.

---

### Choosing the Optimal Parameters

A common question in unsupervised analysis is: *"How many components should I keep?"* and *"How do I choose the number of clusters $K$?"*

```
   PCA: SCREE PLOT (ELBOW)               K-MEANS: INERTIA ELBOW
   
  Var % │                                 Inertia│
   40%  │ *                                      │ \
   30%  │   *                                    │  \
   20%  │     *  <-- Elbow                       │   *  <-- Optimal K (Elbow)
   10%  │       *──*──*                          │    \───────
        └───────────────                         └────────────
          PC1 PC2 PC3 PC4                          K=1 2  3  4  5
```

#### 1. Selecting Number of Principal Components
* **The Scree Plot:** Plot the percentage of variance explained by each PC in descending order. Look for the "elbow" — the point where the curve bends and subsequent PCs add only marginal, flat amounts of variance.


#### 2. Selecting $K$ in $K$-Means Clustering
* **The Inertia Elbow Method:** Inertia measures the total within-cluster distance (how tightly packed the clusters are). As $K$ increases, inertia naturally drops. Plot inertia against $K$; the optimal choice of $K$ is the "elbow" where increasing $K$ yields diminishing returns.
* **The Silhouette Score:** Measures how similar a sample is to its own cluster compared to the nearest neighboring cluster, ranging from $-1$ to $+1$:
  * **Near $+1$:** Sample is tightly bound inside its cluster and far from others (well-separated).
  * **Near $0$:** Sample sits right on the boundary between two clusters.
  * **Negative:** Sample was likely assigned to the wrong cluster.
  * The value of $K$ that maximizes the mean silhouette score across all samples is typically selected.

#### 3. Selecting Clusters in Hierarchical Clustering
* Inspect the **Dendrogram**: Identify the longest vertical lines that are not crossed by any horizontal split. Slicing the dendrogram horizontally through these tall vertical spans produces the most stable, biologically separated clusters.

### The Standard Bioinformatics Workflow: Connecting the Pieces

In real-world bioinformatics (such as bulk RNA-seq or single-cell analysis), dimensionality reduction and clustering are almost always used **together as a cooperative pipeline**:

```
┌────────────────────────────┐
│ Raw High-Dimensional Data  │  (e.g., 20,000 Genes x 500 Patient Biopsies)
└─────────────┬──────────────┘
              │ 1. Standardize (Z-score scaling via StandardScaler)
              ▼
┌────────────────────────────┐
│  PCA Dimensionality Red.   │  (Compress 20,000 genes to Top 20-50 PCs;
└─────────────┬──────────────┘   removes random noise, overcomes curse of dimensionality)
              │
              ├───────────────────────────────────┐
              ▼                                   ▼
┌────────────────────────────┐      ┌────────────────────────────┐
│ Clustering (in PCA Space)  │      │  Visualization (2D Plot)   │
│ (K-Means or Hierarchical)  │      │  (t-SNE or PC1 vs. PC2)    │
└─────────────┬──────────────┘      └─────────────┬──────────────┘
              │                                   │
              └───────────────┬───────────────────┘
                              │ Overlay cluster colors onto 2D projection
                              ▼
               ┌─────────────────────────────┐
               │ Interpretable Visual Subtype│
               │  Discovery & Biomarker ID   │
               └─────────────────────────────┘
```

By performing clustering in **PCA space** rather than raw 20,000-gene space, the clustering algorithm runs faster, avoids noisy background genes, and groups samples based on the primary biological signals.
