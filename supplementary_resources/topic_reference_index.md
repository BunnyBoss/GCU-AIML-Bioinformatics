## 2. Table Schema Specification

This table serves as a living, standardized document for learners, instructors, and teaching assistants. Contributors must follow this column schema when appending new rows:

| Field Name | Header Title | Type / Format | Requirement | Constraints & Guidelines |
|---|---|---|:---:|---|
| `topic` | **Topic** | Markdown String | **Primary Key** | **Exact match constraint:** If `in_curriculum = Yes`, the title must match the official curriculum item verbatim as stated in [curriculum.md](/supplementary_resources/curriculum.md) (including sub-clauses when broken into module topics). |
| `in_curriculum` | **In Curriculum** | Categorical: `Yes` \| `No` | Mandatory | Indicates whether this topic is part of official syllabus `02BMSBI24365` or an auxiliary foundational topic (e.g., Git workflow, Conda environment setup, pedagogical tools). |
| `description` | **Description** | Text | Mandatory | Concise 1–2 sentence summary explaining the biological relevance and computational purpose of the topic. |
| `day` | **Day** | Formatted String | Mandatory | Exact delivery day(s) when the topic was taught (e.g., `Day 1`, `Day 3, Day 4`, or `Planned (Unit X)`). |
| `material` | **Material** | Relative Markdown Links | Mandatory | Must use full repository-root paths (`/units/...` or `/supplementary_resources/...`) so links resolve properly from any directory. |
| `modules` | **Key Modules & Functions** | Inline Code (`...`) | Mandatory | Core Scikit-learn, SciPy, NumPy, or Pandas classes, methods, and functions demonstrated for that topic. |
